# Support

The Cobblemon Kinetics website is a private, pre-production prototype. Support
is best-effort and has no guaranteed response time.

## Before asking for help

1. Confirm Node 24, the repository-pinned pnpm version, and a supported Docker
   runtime are installed.
2. Run `pnpm install --frozen-lockfile`.
3. Reproduce with a clean local Supabase reset when safe.
4. Search open and closed issues.
5. Capture the failing command, browser route, expected result, actual result,
   and relevant sanitized logs.

Redact Supabase keys, OAuth credentials, cookies, GitHub numeric IDs, private
notes, workbook rows, local usernames, and machine-specific paths.

## Where to ask

- Use the website bug form for reproducible application, auth, editor,
  accessibility, publication, or local-database failures.
- Use the data proposal form for schema, migration, importer, catalog, or
  publication-format work.
- Use a feature request for a focused workflow or interface proposal.
- Use the separate
  [mod repository](https://github.com/dallen2021/cobblemon-kinetics/issues)
  for Minecraft gameplay, loaders, Create/Cobblemon compatibility, worlds, or
  JAR releases.

Do not report a suspected security vulnerability publicly. Follow
[SECURITY.md](SECURITY.md).
